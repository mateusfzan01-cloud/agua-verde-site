# Protótipos da loja própria (Prompt A)

- `prototipo-loja.html`: as 4 telas-chave em uma página só, mobile-first, com seletor PT/ES/EN funcionando.
  1. **Início**: widget de rota com preço na hora (26 rotas da tabela Paytour), 4 promessas, selo Tripadvisor Uluwatour, mais vendidos.
  2. **Rota** (exemplo: Aeroporto do Recife → Porto de Galinhas / Muro Alto, R$ 180 ida ou R$ 340 ida e volta).
  3. **Pagamento**: 3 passos sem conta (dados, voo e hotel, Pix ou cartão via Mercado Pago). O Pix é ilustrativo.
  4. **Confirmação / Minha reserva**: voucher, acompanhamento, reenviar, alterar, não encontro o motorista, cancelar (regra de 24 h) e consulta por número + e-mail que só reenvia o link.
- Página publicada (privada, compartilhe pelo menu Share): https://claude.ai/artifact/MPT3GSTEcgBsxMSx6UwAjf
- O arquivo é autocontido: fotos (banco da Paytour, jul/2025) e logo embutidos. Abrir direto no navegador funciona.
- Nada aqui cobra, grava dados ou chama o banco.
